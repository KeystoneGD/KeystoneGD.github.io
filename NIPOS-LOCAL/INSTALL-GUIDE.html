NIPOS Local: install guide

How to put the whole NIPOS till system on one Chromebook, from the zip file, and test it. The Chromebook runs the database and the pages itself; tills, order screens and Backend on other devices connect to it over the venue's Wi-Fi, and it keeps working when the internet goes down.

1. Before you start

  • A Chromebook with 8 GB of memory (4 GB will struggle) that can run Linux. Most Chromebooks from 2019 onwards can.
  • 20 GB or more of free storage for Linux.
  • Internet for the setup. It downloads about 2–3 GB. After setup, NIPOS runs without internet.
  • The charger plugged in, and about 45 minutes.
  • The file NIPOS-LOCAL.zip in the Chromebook's Downloads folder.
School or work Chromebooks are often locked so Linux can't be turned on. If you can't find the Linux option in step 2, that's usually why: use a personal Chromebook.

Typing commands: open the Terminal app (it appears after step 2). To paste a command into it, press Ctrl + Shift + V (or right-click). Press Enter to run it. Each grey box below has a Copy button.

2. Turn on Linux 5–10 min

  1. Open Settings, then About ChromeOS, then Developers (on older ChromeOS it's Advanced → Developers).
  2. Next to Linux development environment, choose Set up (or Turn on).
  3. Keep the suggested username. For Disk size, pick Custom and set it to 20 GB or more (30 GB is comfortable). Sales history grows over time.
  4. Choose Install. When it finishes, a black Terminal window opens. Leave it open.

3. Put the zip into Linux 1 min

  1. Open the Files app.
  2. Go to Downloads and find NIPOS-LOCAL.zip.
  3. Drag it onto "Linux files" in the left-hand list (or right-click it, Copy, open Linux files, Paste).
Don't double-click the zip to open it. ChromeOS opens zips as a read-only folder, and copying files out that way breaks the setup scripts. Unzip it in the Terminal instead, as in the next step.

4. Unzip it 2 min

In the Terminal, run these one at a time:

sudo apt-get update && sudo apt-get install -y unzip
unzip -o NIPOS-LOCAL.zip
cd NIPOS-LOCAL && chmod +x scripts/*.sh

You're now "inside" the NIPOS-LOCAL folder. The other commands in this guide are run from there. If you close the Terminal, get back in with cd NIPOS-LOCAL.

5. Run the setup 10–25 min

scripts/setup.sh

This installs Docker and Supabase (the database, logins and API), downloads everything NIPOS needs so it can later run without internet, makes this Chromebook's own security keys, and starts it all. It prints a lot of text: that's normal. It's finished when you see:

Setup complete. followed by "Next: 1. Create your first Global Admin…"

If it stops with an error part-way, run scripts/setup.sh again: it's safe to run more than once and carries on where it left off. If it says permission denied about Docker, close the Terminal, open it again, and run:

cd NIPOS-LOCAL && scripts/start.sh

6. Create your login and first venue 1 min

Pick your own PIN (6 or more numbers, one nobody else uses), your name, and your venue's name, and put them in place of the examples:

scripts/create-admin.sh 246810 "Your Name" "Main Bar"

That makes you a Global Admin (every permission, every venue) and, on a new install, creates the first venue. You can rename it and add more venues later in Backend.

Optional: a menu to test with

Loads the starter menu (cocktails, draught, spirits, wine, soft drinks, food: 35 categories, 238 products) into that venue. Prices can be changed in Backend afterwards.

scripts/load-starter-menu.sh

7. Open NIPOS 5 min

  1. In Chrome on the Chromebook, go to http://localhost:8080/app.html
  2. Sign in with the PIN from step 6. The NIPOS start screen shows Till, Orders, Kitchen and Backend: each person only ever sees the parts their permissions allow.
  3. Open Backend and set things up (do this while you still have internet):
    • Places → Venues: rename the venue, pick its colour, and add more venues.
    • Team → Staff: add staff, each with their own PIN and permissions.
    • Menu → Products and stops: check the menu and prices (or add your own).
    • Menu → Deals and discounts: Happy Hour and other deals.
    Lost? Type what you're after into the Find box at the top of Backend's menu (for example deals, stop, PIN).

Other addresses on the Chromebook: the till is http://localhost:8080/, the order screen http://localhost:8080/orders.html, Backend http://localhost:8080/backend.html.

8. $YSTEM and Master settings (optional)

Master settings (themes, till layouts and every optional feature) belongs to the hidden $YSTEM account. Create it once; it asks for a password (10+ characters) that isn't shown as you type:

scripts/create-system.sh

Then in Backend, type $YSTEM in the PIN box, press Sign in, and enter that password. System → Master settings appears. Every optional feature starts switched off, so nothing changes until you turn it on. The 17 themes are under Themes and layouts.

9. Connect tills and other devices

Linux on a Chromebook sits in its own private network, so other devices can't reach it until you open two "ports":

  1. Settings → About ChromeOS → Developers → Linux development environment → Port forwarding.
  2. Add port 8080 (TCP), the pages, and port 54321 (TCP), the database API. Switch both on.
  3. Find the Chromebook's Wi-Fi address: Settings → Network → (your Wi-Fi) → Network. It looks like 192.168.1.50.
  4. On each till, tablet or phone, on the same Wi-Fi, open http://192.168.1.50:8080/app.html (using your Chromebook's address). Bookmark it.
Keep it reachable: ask whoever runs the router to give the Chromebook a fixed address (a "DHCP reservation"), so bookmarks keep working. Stop it sleeping: Settings → Device → Power → While charging: Keep display on, turn off Sleep when cover is closed, and keep it plugged in. If it sleeps, every till loses its connection.

10. Test checklist

Tick these off to check everything works:

  • Start screen: sign in, and see the right tiles for your account. Sign in as a staff member with fewer permissions and see fewer tiles.
  • Till: ring up a few drinks, take a card payment and a cash payment.
  • Orders: the order appears on the order screen (on another device too, if you've connected one). Mark it ready and delivered.
  • Stops: put a product on stop in Backend; it shows as on stop on the till within a few seconds.
  • Deals: in Deals and discounts, edit Happy Hour or add a deal and switch it on; the till prices it. Switch it off with its switch; the till's "pricing is on" banner goes within a second or two.
  • Refund an item on the till, then check it in Takings.
  • Reports: make a KPI report and a Full sales breakdown for today; download one as a spreadsheet.
  • Kitchen (if switched on in Master settings): add a kitchen in Places → Kitchens, switch Kitchen open off, and check it disappears from the start screen.
  • Internet off: turn the Chromebook's Wi-Fi to a network with no internet (or unplug the router's internet) and take a sale: it should still work.
  • Z Read: close the shift in Z Reads.
  • Backup: run scripts/backup.sh and check a file appears in Linux files → NIPOS-LOCAL → backups.

11. Day to day

ChromeOS doesn't start Linux by itself, so after every restart of the Chromebook open the Terminal and run:

cd NIPOS-LOCAL && scripts/start.sh
To…Run (inside NIPOS-LOCAL)
Start everythingscripts/start.sh
Stop everything (data is kept)scripts/stop.sh
Back up all datascripts/backup.sh
Restore a backup (replaces all current data)scripts/restore.sh backups/nipos-….sql
Add another Global Adminscripts/create-admin.sh <PIN> "Name"
Create $YSTEM, or change its passwordscripts/create-system.sh
Load the starter menu into a venue with no menuscripts/load-starter-menu.sh "Venue name"
Back up regularly. This Chromebook holds the only copy of the data. After scripts/backup.sh, copy the file from Linux files → NIPOS-LOCAL → backups to Google Drive or a USB stick using the Files app.

Database admin (for checking data directly) is at http://localhost:54323 on the Chromebook.

12. Updating to a newer zip

All your data lives in Docker, not in the folder, so updating the files doesn't touch it. Back up first anyway:

  1. Run scripts/backup.sh and copy the backup somewhere safe.
  2. Put the new NIPOS-LOCAL.zip into Linux files (step 3), replacing the old one.
  3. In the Terminal: 
    cd ~ && unzip -o NIPOS-LOCAL.zip && cd NIPOS-LOCAL && chmod +x scripts/*.sh && scripts/start.sh
    start.sh applies any database changes in the new version and keeps all existing data. Your keys (in the hidden .nipos folder) and backups stay as they are.
  4. On each till, reload the page.

13. What's different from the online NIPOS

  • Alerts when the page is closed (push notifications) only work on the Chromebook itself: browsers only allow them over a secure connection. While a page is open, sounds, banners and pop-ups work on every device.
  • "Add to Home Screen" as an app on phones and tablets needs a secure connection too, so use a browser bookmark on those devices.
  • Discord messages (stops, orders, Z Reads) only send while the Chromebook has internet. Everything else works offline.
  • Daily summary email isn't available.
  • Sales, staff and menus are separate from the online NIPOS: nothing is shared between the two.

14. If something goes wrong

You seeDo this
"Supabase isn't running" or the pages say they can't connectscripts/start.sh
"Docker isn't running" or "permission denied" just after setupClose the Terminal, open it again, then cd NIPOS-LOCAL && scripts/start.sh
scripts/setup.sh: Permission deniedchmod +x scripts/*.sh, then try again. (Usually means the zip was opened by double-clicking rather than unzipped in the Terminal.)
"Incorrect PIN"Check the PIN; or make another Global Admin with scripts/create-admin.sh
Backend has no menu items or venuesRun step 6 again (it only creates a venue if there are none), then scripts/load-starter-menu.sh
Other devices can't connectCheck both ports are forwarded and switched on (step 9), the device is on the same Wi-Fi, and the Chromebook's address hasn't changed. Make sure the Chromebook hasn't gone to sleep.
Setup is very slow or fails downloadingCheck the internet, close other Chrome tabs to free memory, and run scripts/setup.sh again.
Everything is slowClose other apps and tabs. NIPOS Local needs about 3 GB of the Chromebook's memory.

Starting again from scratch

This deletes every sale, venue, staff member and setting on this Chromebook. Only do it on a test install, after a backup if there's anything you want to keep: 
cd ~/NIPOS-LOCAL && scripts/stop.sh; supabase stop --no-backup && scripts/start.sh
Then repeat from step 6.
