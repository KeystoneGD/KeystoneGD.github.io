Master settings

Features

Every feature here starts switched off, so you can set it up first. Nothing changes on the tills until you switch it on.

Master theme

Changes the colours on every till, order screen and Backend. Devices that are open switch within a minute. Each device's own switch still flips between the theme's normal colours and its dark mode. Green (ready), red (problem or refund) and yellow (in progress) keep their meaning in every theme.

Till layout

How the menu looks on every till. Each layout has a phone and a tablet version, and each device picks the right one by itself. Taking payment, the order panel and every option picker stay the same in all of them.

Activity

The Activity log is switched off, so nothing new is being recorded. Switch it on in Features.

Remove sales

Clears out test transactions. Removes every sale, refund, tip, abandoned order, open order and Z Read for the venue you pick. Takings, Past Orders and the charts start again from nothing. This can't be undone.
